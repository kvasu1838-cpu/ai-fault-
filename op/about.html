About The Project

AI-based fault diagnosis using rule-based reasoning

INTRODUCTION

What is AI Fault Diagnosis?

AI Fault Diagnosis is the process of using Artificial Intelligence techniques to identify possible causes of failure in a system.

In this project, a rule-based expert system is developed using Forward Chaining and Backward Chaining.

The system receives symptoms from the user, compares them with rules in a knowledge base, and produces possible faults.

Project Objectives

Develop a rule-based expert system.
