Diagnosis Examples

Examples of rule-based fault diagnosis

Example 1 — Power Supply Failure

Symptoms

  • Computer does not start
  • Power LED is off

Rule

IF no_power AND no_led THEN power_supply_failure

Result

Possible Power Supply Failure

Example 2 — Cooling Failure

Symptoms

  • System is overheating
  • Cooling fan is not working

Rule

IF overheat AND fan THEN cooling_failure

Result

Possible Cooling System Failure

Example 3 — Hard Disk Failure

Symptoms

  • Strange noise
  • Disk error

Rule

IF noise AND disk THEN hard_disk_failure

Result

Possible Hard Disk Failure
